# ONSET

ONSET is a performance-oriented task management system designed to convert complex exam syllabi into structured, daily executable plans. By utilizing a high-contrast, industrial design language, the platform minimizes cognitive load and prioritizes user focus on long-term academic consistency.

Problem Statement
Students often face "starting friction" when beginning exam preparation, spending more time organizing complex syllabi than actually studying. Traditional productivity tools frequently use cluttered, overly decorative interfaces that distract from high-stakes goals. There is a critical need for a streamlined, high-contrast system that removes visual noise and provides a direct, executable roadmap from a broad syllabus to daily tasks.

How it Works
The application operates through a streamlined four-step workflow:

Syllabus Integration: Users provide their specific exam objectives or subject matter to the system.
Plan Generation: The platform decomposes large-scale goals into granular, daily task cards to ensure steady progress.
Performance Monitoring: A centralized dashboard provides real-time data on productivity percentages and overall syllabus completion.
Consistency Tracking: Every session is logged into a geometric activity heatmap, allowing users to visualize study patterns and maintain streaks.
Tech Stack
Frontend Architecture
The frontend is built as a lightweight, dependency-free application to ensure maximum speed and reliability:

HTML: Defines a semantic hierarchy that ensures clear data presentation.
CSS: Implements a "Minimalist-Brutalist" aesthetic featuring a deep charcoal palette, 2px sharp borders, and cyan-accented focus states.
Vanilla JavaScript: Manages tactile haptic feedback and real-time UI updates for a responsive user experience.
